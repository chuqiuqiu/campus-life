# 轻享校园生活服务平台 —— 完整部署文档
> 技术栈：SpringCloud Alibaba 微服务（Nacos / Gateway / Sentinel / Seata）+ MySQL 8.0 + Redis + Vue2 + Nginx
> 目标环境：虚拟机 `192.168.100.128`，Docker 已预装 MySQL、Redis、Nacos、Seata、Nginx

---

## 一、项目整体架构

```
                        浏览器
                          │
                    ┌─────▼─────┐
                    │  Nginx    │  :8088  静态资源 + 反向代理
                    │ :8088     │  /api → 网关
                    └─────┬─────┘
                          │ /api/xxx
                    ┌─────▼─────┐
                    │ campus-   │  :8080  路由转发 / JWT鉴权 / 跨域
                    │ gateway   │
                    └──┬──┬──┬──┘
         ┌─────────────┘  │  └─────────────┐
   ┌─────▼─────┐  ┌──────▼──────┐  ┌──────▼──────┐  ┌──────▼──────┐
   │ user-     │  │ item-       │  │ activity-   │  │ info-       │
   │ service   │  │ service     │  │ service     │  │ service     │
   │ :8081     │  │ :8082       │  │ :8083       │  │ :8084       │
   └─────┬─────┘  └──────┬──────┘  └──────┬──────┘  └──────┬──────┘
         │                │                │                │
      campus-user     campus-item      campus-activity   campus-info
      MySQL 库           MySQL 库           MySQL 库           MySQL 库
         └───────────────┴────────────────┴────────────────┘
                    Nacos(:8848) 注册/配置    Redis(:6379) 缓存/计数
                    Seata(:8091) 分布式事务   Sentinel(:8858) 控制台
```

**业务场景（跨服务示例）**：发布闲置 → item-service 插入闲置 + 通过 Feign 调 user-service 加积分，由 Seata AT 保证分布式一致性。

## 五、Nacos 配置中心初始化

在 Nacos 控制台（http://192.168.100.128:8848/nacos）新建以下共享配置（Data ID / 格式 yaml）：

### 1. `shared-log.yaml`（公共日志）
```yaml
logging:
  level:
    com.campus: debug
  pattern:
    dateformat: HH:mm:ss:SSS
  file:
    path: "logs/${spring.application.name}"
```

### 2. `shared-swagger.yaml`（公共接口文档开关）
```yaml
knife4j:
  enable: true
```

### 3. `shared-seata.yaml`（公共 Seata 客户端配置，user/item 两个服务引用）
```yaml
seata:
  registry:
    type: nacos
    nacos:
      server-addr: 192.168.100.128:8848
      application: seata-server
      group: SEATA_GROUP
  tx-service-group: campus_tx_group
  service:
    vgroup-mapping:
      campus_tx_group: default
  enable-auto-data-source-proxy: true
```

> 各服务 `bootstrap.yaml` 通过 `shared-configs` 自动拉取以上配置，也支持 Nacos 动态刷新。

## 六、后端启动步骤

```bash
# 1. 打包（在 campus-life 根目录）
mvn clean package -DskipTests

# 2. 按依赖顺序启动（先 Nacos/Seata/MySQL/Redis，再依次启动服务）
java -jar user-service/target/user-service.jar          # 8081
java -jar item-service/target/item-service.jar          # 8082
java -jar activity-service/target/activity-service.jar  # 8083
java -jar info-service/target/info-service.jar          # 8084
java -jar campus-gateway/target/campus-gateway.jar      # 8080（最后启动网关）
```

启动成功后，可在 Nacos 服务列表看到 5 个服务实例。

## 十二、常见问题排查（踩坑记录，务必先看这里）

### 1. JDK 17 启动报 `InaccessibleObjectException`（cglib / MyBatis-Plus）
- **现象**：`module java.base does not "opens java.lang"` 或 `"opens java.lang.invoke"`
- **原因**：JDK 17 强封装模块，Seata 的 cglib 和 MyBatis-Plus 3.4.x 需要反射访问 JDK 内部
- **解决**：
  - Seata：IDEA 运行配置 VM options 加 `--add-opens java.base/java.lang=ALL-UNNAMED`
  - MyBatis-Plus：**已升级到 3.5.3.2**（源码级解决，不再需要 java.lang.invoke 参数）

### 2. 服务启动报 `no available service found in cluster 'default'`（Seata）
- **原因**：seata-server 没启动，或客户端用 nacos 注册模式找不到 server
- **解决**：`shared-seata.yaml` 已改为 file 直连模式（`grouplist: 192.168.100.128:8091`），先启动 seata-server 容器（`docker run -d --name seata-server -p 8091:8091 -e SEATA_IP=192.168.100.128 --network hm-net seataio/seata-server:1.5.2`）

### 3. Nacos 起不来，日志报 `No DataSource set`
- **原因**：Nacos 配了外部 MySQL 存储但库没初始化，或镜像里没有 MySQL 版 SQL
- **解决**：改用内置 Derby 单机模式（`-e MODE=standalone`，不带 MySQL 环境变量），对项目无影响

### 4. 网关返回 503 Service Unavailable
- **原因**：Spring Cloud 2021 中 gateway 与 loadbalancer 已拆分，`lb://服务名` 路由需要 `spring-cloud-starter-loadbalancer`
- **解决**：campus-gateway 已显式引入该依赖（对标黑马商城）

### 5. Feign 调用报 `UnknownHostException: user-service`
- **原因**：`spring-cloud-starter-alibaba-nacos-discovery` **不传递** loadbalancer，Feign 无法做服务名负载均衡，把服务名当 DNS 解析
- **解决**：item-service、activity-service 已显式加 `spring-cloud-starter-loadbalancer`

### 6. 登录后执行写操作（收藏/发布等）仍提示未登录、跳登录页死循环
- **原因**：网关白名单用了 `/items/**` 整段放行，导致即使带 token 也不解析、不透传 user-info，服务端永远拿不到 userId
- **解决**：网关白名单改为**接口粒度**（只放行公开查询），写操作必须登录。注意 `{id:[0-9]+}` 正则限定数字 id，避免误伤 `/me`、`/page`、`/favorites`、`/top`

### 7. 接口返回 `LocalDateTime not supported by default`
- **原因**：自定义 `@Primary ObjectMapper` 覆盖了 Spring Boot 自带（含 JavaTimeModule）的 ObjectMapper
- **解决**：改用 `Jackson2ObjectMapperBuilderCustomizer` 定制（只加 Long→String，不覆盖），对标黑马商城

### 8. 中文乱码 / YAML 解析失败 `while scanning a quoted scalar`
- **原因**：用 PowerShell 5.1 的 `Get-Content/Set-Content` 修改 UTF-8 文件时按 GBK 误读写
- **解决**：所有 yaml 已用 UTF-8 重写；以后改文件用 IDEA 或带 UTF-8 的工具，并保持 IDEA `File Encodings` 全为 UTF-8

### 9. 连不上 MySQL / Redis
- **注意**：本机 MySQL 是 **3307**（黑马商城同款），Redis **无密码**，配置已适配（`application-dev.yaml` 的 `hm.db.pw`、`hm.redis.pw`）
- 若密码不同，只改各服务 `application-dev.yaml` 即可

### 10. 启动顺序
- **必须**：`user → item → activity → info → 网关最后启动`（网关启动时要从 Nacos 拉全实例列表；现在 LB 依赖补齐后，即使顺序乱也会自动恢复，但按顺序最稳）

### 11. 多网卡导致服务注册 IP 异常
- **现象**：Nacos 里实例 IP 是 `192.168.43.39`（WLAN）而非虚拟机网段
- **说明**：全在本机调试时无影响（IP 可达）；如需固定，可在 `application.yaml` 加 `spring.cloud.nacos.discovery.ip: 127.0.0.1`
